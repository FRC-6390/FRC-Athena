# V2 Mechanism Authoring Examples

These files show the V2 mechanism API in the preferred order:

- annotation style is the live, executable example
- structured style is kept as a commented reference inside the same file
- flow style is kept as a commented reference inside the same file

Current files:

- `SimpleMotorMechanismExamples.java`
- `FlywheelMechanismExamples.java`
- `ArmMechanismExamples.java`
- `ElevatorMechanismExamples.java`
- `TurretMechanismExamples.java`

Superstructure examples still live under `../superstructure` because the annotation path is currently mechanism-only.
