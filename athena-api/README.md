# athena-api

Public declarations and common value types that are safe for all robot projects.

This module must not depend on runtime, WPILib vendor APIs, or Athena vendor
adapters.

## Current Slice

- Stable built-in motor, encoder, IMU, and camera keys.
- Reusable motor, encoder, IMU, and camera hardware aliases.
- Tests for key stability, marker interfaces, default buses, and null safety.

## Dependencies

- Production: none.
- Test-only: none.
